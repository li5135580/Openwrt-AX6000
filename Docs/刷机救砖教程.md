# 京东云百里 AX6000（RE-CP-03）刷机救砖教程

> ⚠️ **平台警告（先看这个）**
>
> 百里是**联发科 MT7986A（Filogic 830）**平台，与雅典娜 AX6600（高通 IPQ6010）是两套完全不同的硬件：
>
> - ❌ 雅典娜的不死 U-Boot、双分区 GPT 分区表、**USB 9008 救砖工具**，一律**不能**用于百里，刷错必砖
> - ❌ 雅典娜固件不能刷进百里，反之亦然
> - ✅ 百里的救砖手段是 **TTL 串口**（3.3V 电平，115200 波特率），不是 9008

## 1. 硬件与启动链介绍

百里的关键硬件参数：

| 参数 | 规格 |
|------|------|
| SoC | MediaTek MT7986A（4× Cortex-A53） |
| RAM | 1GB DDR4 |
| 存储 | 128GB eMMC（`/dev/mmcblk0`，含 boot0/boot1 硬件引导分区） |
| 以太网 | 4× 1GbE + 1× 2.5GbE（RTL8221B） |
| 无线 | 2.4GHz 4×4 + 5GHz 4×4（160MHz），SoC 内置 |

联发科的启动链与高通完全不同，共三级：

```
BL2（preloader.bin，位于 eMMC boot0 分区）
  → FIP（bl31-uboot.fip，含 BL31 安全监控 + U-Boot）
    → GPT 分区表 + 固件（sysupgrade.itb 写入固件分区）
```

每个 Release 里对应这三个层级的文件：

| Release 文件 | 作用 | 写入位置 |
|------|------|------|
| `*-preloader.bin` | BL2 引导（emmc-ddr4 变体） | `/dev/mmcblk0boot0` |
| `*-bl31-uboot.fip` | BL31 + U-Boot | GPT 中的 `fip` 分区 |
| `*-gpt.bin` | eMMC GPT 分区表 | `/dev/mmcblk0` 头部 |
| `*-filogic-jdcloud_re-cp-03-*-sysupgrade.itb` | 固件本体 | 固件分区（U-Boot 或系统内刷入） |

无线校准数据（ART / EEPROM 分区，含 MAC 地址）**每台机器唯一，丢失无法恢复**，备份时务必包含。

## 2. 刷机前准备

工具软件：

- SSH 工具：Xshell / PuTTY
- 文件传输：WinSCP
- **USB 转 TTL 串口模块（3.3V 电平）**：刷机前先确认能正常读出启动日志，这是唯一可靠的救砖手段
- U 盘或移动硬盘（备份 128GB eMMC 用，可用空间需大于实际占用）

备份（SSH 登录原厂系统后执行，示例）：

```bash
# 查看分区布局
blkid
lsblk

# 整盘备份到 U 盘（假设备份介质挂载在 /mnt/sda1，耗时较长）
dd if=/dev/mmcblk0 of=/mnt/sda1/mmcblk0-full-backup.bin bs=1M conv=fsync

# 引导分区单独备份
dd if=/dev/mmcblk0boot0 of=/mnt/sda1/mmcblk0boot0-backup.bin
dd if=/dev/mmcblk0boot1 of=/mnt/sda1/mmcblk0boot1-backup.bin
```

TTL 接线：拆机后找到板载串口焊点（GND / TX / RX，**只接这三根，不要接 VCC**），波特率 115200。先只读验证：上电能看到启动日志输出，说明接线正确。

## 3. 首次刷入流程（原厂 → ImmortalWrt）

> 百里没有 factory 镜像，首次刷入需要借助 U-Boot。具体步骤以 ImmortalWrt 官方源码中 `jdcloud_re-cp-03` 的设备提交说明及恩山无线论坛的百里专帖为准，以下为通用流程概述：

1. **开启原厂固件 SSH**：方法随原厂固件版本变化，请查阅恩山无线论坛（right.com.cn）百里 / RE-CP-03 专帖获取当前版本的开启方法
2. **完成第 2 节的整盘备份**，确认备份文件已拷贝到电脑
3. **刷写启动链**：将 Release 中的 `preloader.bin`、`bl31-uboot.fip`、`gpt.bin` 写入对应位置（写入工具与命令以社区教程为准，写错会导致无法启动，务必先备份）
4. **进入 U-Boot**：TTL 串口中断启动，或按住复位键上电进入 U-Boot Web / TFTP 刷机模式
5. **刷入固件**：选择 `sysupgrade.itb` 固件文件刷入，等待重启
6. 首次启动后默认管理地址 `192.168.10.1`，WiFi 名称 `OWRT`、密码 `12345678`

## 4. 系统内升级（sysupgrade）

已经是本固件后，日常升级无需动启动链：

- LuCI 界面：「系统 → 备份/升级」上传 `sysupgrade.itb`
- 或命令行：
  ```bash
  sysupgrade -v /tmp/*-sysupgrade.itb
  ```

> master 为每日滚动快照，升级前建议在 LuCI 备份配置；跨大版本升级不建议保留配置。

## 5. 救砖（TTL + U-Boot）

百里没有高通的 9008 模式，救砖完全依赖 TTL 串口：

1. 接好 TTL（115200），上电观察启动日志
2. **U-Boot 还活着**（日志停在 U-Boot 或可中断）：直接进入 U-Boot 刷机模式重刷固件即可
3. **U-Boot 已损坏**（完全无输出或停在 BL2）：需要用编程器或社区提供的底层手段重写 `mmcblk0boot0` 中的 BL2，此时第 2 节的整盘备份就是最后的保障

预防永远优于救砖：

- 刷机前必做整盘备份，并确认备份已拷贝出路由器
- 启动链文件（bl2/fip/gpt）与固件必须来自**同一个 Release**，不要混用不同日期构建的版本
- 刷机过程中保证供电稳定
